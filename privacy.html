Privacy Policy — Beco Video Uploader

Beco Video Uploader is a private tool used only by its owner (Husanboy Tohirov) to upload and manage videos on his own YouTube channels: BECO PLAST, ProKuzov Almaty, Silent Garage and Dirty to Clean.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information we access, use and store

With the owner's authorization (OAuth 2.0) the tool uploads video files, sets title, description, thumbnail and privacy status, and reads basic information (channel id and title) of the owner's channels. OAuth tokens are stored only on the owner's private server with restricted file permissions. The tool does not collect data from other YouTube users and does not use cookies or tracking.

Sharing

No data is sold, shared with third parties or used for advertising.

Deletion and revocation

Authorization can be revoked at any time on the Google security settings page. On revocation or on request to thusanboy2001@gmail.com, stored tokens and any API data are deleted within 7 days. Stored API data is not kept longer than 30 days.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
